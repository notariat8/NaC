# Service Model

Dieser Ordner bündelt Notariats-Scope, Betriebsleistungen, Tenant-Ownership
und Exit. NaC beschreibt ausschließlich Notariat as Code; nicht-notarielle
Produktpfade sind kein gültiger Scope dieses Repositories.
