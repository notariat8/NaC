# Implementation plan: SharePoint indexes from the declared schema

Date: 29 September 2026. Leading [Issue #760](https://github.com/notariat8/NaC/issues/760). Based on the approved [specification](../specs/2026-09-29-m365-index-drift-design.md). This plan covers repository code and synthetic checks only.

1. **Test first (AC-760-1/2):** In [tests/test_teams_sharepoint_graph_data_plane.py](../../../../tests/test_teams_sharepoint_graph_data_plane.py), cover missing, duplicate and unknown `indexed_columns`, a unique index not declared in that list, and every expected index payload with positive and negative cases.
2. **Provisioning plan (AC-760-1/2):** [schema.py](../../../../src/nac_m365_graph/schema.py) validates index declarations and derives Graph column payloads from their list context; [provisioner.py](../../../../src/nac_m365_graph/provisioner.py) passes that context to each `ensure_column` operation. Existing owner gates and Graph write boundaries remain unchanged.
3. **Test first and read-only drift path (AC-760-3/4):** Test synthetic correct and incorrect site/list/column bindings, missing, duplicate and unindexed columns, Graph errors, paging, and malformed responses. The comparator checks only fixed Graph metadata GET path keys in an in-memory JSON snapshot and cannot call a Graph client. It emits redacted counts/error codes and fails closed also on incomplete or paginated metadata. Tests prove zero write, item, file, and real provider calls, as well as zero credential constructions on failed preflight.
4. **CLI and contract (AC-760-3/4/5):** `nac m365 teams-sharepoint drift` gets explicit workspace selection and a binding preflight before credentials. In #760, the CLI tenant read stays blocked: a verifiable owner record binding the exact read operation, workspace, tenant/site, and operator account/principal is not yet available. `--owner-approved` alone cannot substitute for that record. Test the pure comparator with a synthetic offline snapshot; the provider apply placeholder remains blocked too. Record Graph endpoints and boundaries in the [data-plane contract](../../../../workflows/contracts/teams-sharepoint-graph-data-plane.contract.json).
5. **Review and validation (AC-760-5):** Synchronize DE/EN CLI docs and spec traceability; review code and tests against this plan and fix findings. Run focused tests, validator, Graft Build/Check, and the Windows strict doctor locally. Inspect the full working-tree diff before committing, then the actual `main...HEAD` patch, file list, and commit list. Protected-PR publication and remote CI belong to a separately authorized delivery step. No tenant read, index PATCH, deployment, or Teams functional test in this step.

Passing local gates proves only the repository fix. The previously observed lack of index-PATCH permission and the Teams 403 cause remain separate operational boundaries.
